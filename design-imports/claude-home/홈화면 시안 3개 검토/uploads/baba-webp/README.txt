바바 캐릭터 부품 (WebP · 투명 배경 · 모두 1200x1600 같은 캔버스)

겹치는 순서(아래부터):
  base-tail → base-body → (옷) → base-feet → base-arms → base-muzzle → base-mouth
  → base-cheeks → base-eyes → (눈 아이템) → base-ears → (모자) → base-ears-front

- 모든 파일을 같은 크기의 상자에 같은 위치(0,0)로 겹치면 된다. 위치를 따로 맞추지 않는다.
- base-ears-front 는 "귀가 모자를 뚫고 나오는" 모자를 쓸 때만 켠다 (hat-beanie-2).
- hat-beanie 는 귀 사이에 얹는 모자, hat-beanie-2 는 귀가 뚫고 나오는 모자(시험용).
- 원본: 팀 피그마 「대추노노」 > 디자인 수정 > 섹션 「바바 캐릭터」의 Baba 컴포넌트.
