`docs/spec/` 과 같은 규칙을 따른다 — **직접 수정하지 않는다.** 갱신은 원본에서 재복사한다.

## 정본 규칙

- 문서(`design-system.md` · `app-flow.md` · `data-model.md`)가 구현 기준.
- **값이 어긋나면 `prototype/*.dc.html` 의 값이 이긴다** (원본 [README.md](README.md) 규칙).
- 문안(마이크로카피)은 예외 — 아래 오탈자 때문에 **문안은 `docs/spec/screens/` 것을 쓴다.**

## 알려진 불일치 · 주의 (반입 시점 검수)

1. **홈 날씨 스카이 색이 문서·프로토타입이 다르다.** `design-system.md` §1.5 는 맑음
   `#A9CBDD/#BFDCE8/#EAF0E2` 인데 `홈.dc.html` 의 `WEATHER` 맵은
   `#CFE9F0/#DCEEEF/#EAF4EA` 다(흐림·비도 다름). 정본 규칙대로 **프로토타입 값**을 쓴다.
2. **폰트 서술 한 곳이 낡았다.** `README.md` 구현 순서 1에 "Gaegu, Gowun Dodum",
   `app-flow.md` §2.1 에 "29px Gaegu" 가 남아 있으나, `design-system.md` §2 와
   프로토타입 8장 전부 **Pretendard 단일**(400/700)이다. Pretendard 를 따른다 → PLAN.md D6.
3. **프로토타입 문안에 오탈자가 있다** — 그대로 옮기지 말 것.
   마이: 「이혀하로 답변해드리게요」 「탈톴 시」 「요슭할」 「맡개 둠셔도 괜싮습니다」 ·
   쉼터: 「머벅다 사라짐에요」.
4. **구현 대상이 아닌 것** — 자체 한글 조합 키보드(OS 키보드 사용 · README 경고),
   상태바 목업, 탭바 아이콘의 자리표시 사각형(실 아이콘은 `LineIcons` 계열로 신규 제작),
   `전체 화면.dc.html`(프레젠테이션 셸).
5. 감정 아이콘 `mood-*.png` 9종은 프로토타입에선 보관함만 참조하지만,
   `design-system.md` §1.4 는 **앱 전체 감정 표현의 단일 소스**로 규정한다(캘린더 22px ·
   리스트 34px · 기록 카드 32px).
