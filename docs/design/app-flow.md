# 앱 플로우 & 화면 스펙

기준 캔버스: 세로 모바일 1장(프로토타입 430×883). 모든 화면은 `상태바 → 콘텐츠(스크롤) → 하단 탭바` 세로 스택입니다.

---

## 1. 정보구조

```
탭  홈 · 쉼터 · 보관함 · 리포트 · 마이
     │
홈 ──┼─ 병아리 탭 ──▶ 하루 회고(챗) ──▶ 일기 ──[일기 저장]──▶ 쉼터/행동카드 상세
     └─ 일정 CRUD · 완료 → 감정 선택 시트

쉼터 ─┬─ 행동카드 ─┬─ (카드 탭) ─▶ 행동카드 상세
      │            └─ 캘린더로 날짜 이동(카드 있는 날만)
      └─ 룸 3종: 대나무 숲 / 감각 연못 / 걱정 상자

보관함 ─┬─ 캘린더 뷰 ─ 날짜 선택 ─▶ 그날 기록 카드 ─(일기 탭)─▶ 일기(읽기 전용)
        └─ 리스트 뷰 ─ 월 필터 · 감정 필터 · 검색 ─▶ 일기(읽기 전용)

리포트 ─ 주간 감정 도넛 · 통계 · "이 주의 기록 보기" ─▶ 보관함
마이   ─ 알림 설정 / 온보딩 다시보기 / 문의 / 정책 / 로그아웃 / 탈퇴
```

핵심 규칙 3개:

1. **일정은 있어도 없어도 되는 존재**다.
2. **일기는 일정이 없어도 쓸 수 있다.**
3. **일정 완료 감정은 일정이 있을 때만 선택 가능**하며, 선택을 건너뛸 수 있다.

## 2. 화면별 스펙

### 2.1 홈 `/`

| 영역 | 내용 |
| --- | --- |
| 상태바 | 시간·배터리. **날짜 헤더와 같은 스카이 배경**(`skyTop`)을 공유 |
| 헤더 | 날짜(29px Gaegu) + 날씨 아이콘·라벨 |
| 씬 | 320px. 날씨별 하늘 그라디언트, 구름, 3중 언덕, 카피바라(우), 병아리(좌, 탭 → 회고), 말풍선 |
| 일정 카드 | "오늘 일정" + `＋ 추가`. 스크롤 영역 206px |
| 탭바 | 5탭. 입력 레이어가 열리면 `translateY(110%)`로 내려감 |

일정 인터랙션
- `＋ 추가` → 하단 입력 바 + 키보드 올라옴, 입력 후 완료/Enter로 추가
- 제목 탭 → 같은 입력 바에 기존 값 로드(편집 모드, 🗑 삭제 버튼 노출 → 확인 모달)
- 완료 원 탭 → 완료 처리 후 **감정 선택 시트**. 재탭 시 미완료로 되돌리고 감정도 지움
- 핸들 드래그 → 순서 변경(놓일 자리 점선 슬롯 표시)
- 빈 화면일 때도 일정이 0개인 상태가 정상이며, 카드는 유지합니다

### 2.2 하루 회고 `/reflect`

카피바라와의 챗. 3스텝 고정.

| 스텝 | 타입 | 내용 |
| --- | --- | --- |
| 1 | 자유 입력 | "{이름}님, 지금은 {감정} 마음이 가장 가까이 있군요." + "오늘은 어떤 이야기를…" |
| 2 | 슬라이더 | "오늘 하루는 얼마나 만족스러웠나요?" (1~10, 기본 7) |
| 3 | 선택 + 직접 입력 | 충분히 쉬기 / 할 일을 하나만 줄이기 / 누군가와 이야기하기 |

- 봇 발화는 문장당 540ms 지연, 사용자 응답 후 700ms 뒤 다음 스텝
- 3스텝 완료 → "오늘 이야기 고마워요. 일기로 정리해 볼게요." → 1.1초 후 **일기**로 이동
- 1스텝 감정 문구는 그날의 대표 감정(일정 완료 감정/일기 감정)에서 가져옵니다

### 2.3 일기 `/diary/:date`

탭 2개: **내 시선** / **다른 시선**. 각각 페이지 넘기기 형태의 본문.

| 모드 | 진입 | 저장 버튼 |
| --- | --- | --- |
| 작성(회고에서 이어짐) | `/reflect` 완료 | **있음** — 누르면 캐릭터 말풍선 후 행동카드 상세로 이동 |
| 읽기(보관함에서 열기) | `?mode=view&y=&m=&d=` | **없음**, ✕는 보관함으로 |

- 헤더: 날짜 + 그날 감정 태그(감정 팔레트 색)
- 하단: 그날 일정 목록(완료 점 = 감정색). **일정이 없는 날은 이 카드 자체를 숨김**
- "다른 시선"은 같은 하루를 카피바라 관점에서 다시 써 준 글. 두 시선 모두 항상 존재해야 합니다

### 2.4 쉼터 `/rest`

허브: 상단 **행동카드** 배너(초록 그라디언트, "보러가기 ›") + 언덕 아래 룸 타일 3개.

| 룸 | 기능 |
| --- | --- |
| 대나무 숲 | 하고 싶은 말 입력 → 말풍선이 떠오르고 서서히 사라짐 |
| 감각 연못 | 4-7-8 호흡. 원 크기·문구·카운트가 초 단위로 변함, 시작/멈추기 |
| 걱정 상자 | 걱정 추가/개별 삭제/모두 버리기, 상자 열기·닫기 |

행동카드 뷰 `/rest/cards`
- 그날 카드: 상황 / 제안된 행동 / 수행 체크 / 느낀 점 — **자세히 보기 없이 바로 노출**
- 카드 전체 탭 → 상세. 체크·입력은 상세로 넘어가지 않음
- 캘린더: 카드가 생성된 날 전부 초록 채움, 월 이동은 2025-08 ~ 현재 월로 제한, 월 이동 시 그 달 마지막 카드 날 자동 선택

상세 `/rest/cards/:date`
- 상황 → 제안된 행동 → 수행 여부·느낀 점 → **지난 기록 리스트 6건**(과거 카드에서 최신순)

### 2.5 보관함 `/archive`

세그먼트: **캘린더** / **리스트**.

캘린더 뷰
- 월 이동 `‹ ›`, 셀에 날짜 + 감정 아이콘
- 선택일 아래 기록 카드 하나: (일기가 있으면) 일기 행 + 그날 일정 행들. 일기 없고 일정만 있는 날도 카드 표시
- 일기 행 탭 → `/diary/:date?mode=view`

리스트 뷰
- 검색 필드(일기 본문 검색) — 탭하면 키보드 올라옴
- 감정 칩 필터 — 재탭 해제, "전체" 칩 없음
- `2026년 8월 ▾` 라벨 탭 → **라벨 바로 아래에 월 목록이 겹쳐 펼쳐짐**(모달 아님, 텍스트 폭만큼, 최대 260px 스크롤). 기록 있는 월을 내림차순으로 전부 나열. 건수 표기 없음
- 리스트 항목: 감정 아이콘 + 날짜 제목 + 본문 발췌 + 감정 태그 → 일기 읽기 화면

### 2.6 리포트 `/report`

- 주 단위(일요일 시작) 이동 `‹ ›`, 2025-08 첫 주까지
- 감정 도넛: 그 주 일기 감정 + 일정 완료 감정을 합산해 상위 5개 비율. 범례 칩 탭 → 도넛 중앙 라벨 변경
- 통계 3줄: 이번 주 일정(n개 중 m개 완료) / 행동카드(n개 중 m개 실행) / 일기(n일 기록). 없으면 "기록 없음"
- 코멘트: 최다 감정 비율 45% 이상 → "가장 많았어요", 고르면 → "고르게 지나갔어요", 기록 0 → "비어 있는 주도 하나의 기록"
- "이 주의 기록 보기" → 보관함

### 2.7 마이 `/my`

닉네임·회고 수 헤더 + 그룹 리스트.

| 그룹 | 행 | 동작 |
| --- | --- | --- |
| 앱 설정 | 알림 설정 | 시트: 스위치 + 시간 20:00~23:00 선택 → 토스트 |
| | 온보딩 다시하기 | 시트 3단계 → "다 봤어요" |
| 지원 | 문의하기 | 시트: 텍스트 입력 → 전송(빈 값이면 토스트로 경고) |
| | 정책 · 약관 | 시트: 아코디언 목록 |
| 계정 | 로그아웃 | 토스트 후 홈으로 |
| | 회원 탈퇴 | 2단 확인 모달 → 접수 토스트 후 홈으로 |

## 3. 입력 레이어 규칙 (전 화면 공통)

1. 입력이 열리면 **하단 탭바는 아래로 내려감**(`translateY(110%)`).
2. 키보드·감정 시트·월 목록 등 아래에서 올라오는 레이어는 **화면 아무 곳을 탭하면 닫힘**. 닫힘도 애니메이션이 보여야 하므로 조건부 마운트가 아니라 `translateY` + `pointer-events`로 제어합니다.
3. 닫힘 처리 시 입력 필드 `blur()`까지 해야 다시 탭했을 때 열립니다.
4. 딤이 필요한 레이어(감정 시트·모달)와 필요 없는 레이어(키보드·월 목록)를 구분합니다. 딤 없는 레이어는 투명 오버레이로 탭을 받습니다 — **이 오버레이의 z-index가 패널보다 낮아야** 패널 내부 클릭이 먹히지 않는 문제가 생기지 않습니다(프로토타입에서 실제로 겪은 버그).
5. 실제 앱에서는 OS 키보드를 쓰고, 위 1·2번 규칙만 유지합니다.

## 4. 상태 유지 / 전환

- 화면 간 이동은 라우팅. 프로토타입은 파일 이동 + 쿼리스트링(`?view=card`, `?mode=view&y=&m=&d=`)으로 흉내낸 것이므로, 실제 구현에서는 라우트 파라미터로 옮깁니다.
- 회고 → 일기 → 행동카드 상세는 **하나의 플로우**입니다. 뒤로가기 시 회고를 다시 재생하지 않고 홈으로 빠지게 하세요.
- 일기 읽기 모드에서 뒤로가기는 항상 보관함으로 복귀(스크롤 위치·필터 유지).
- 오늘 날짜 기준: 미래 날짜는 선택해도 기록이 없으므로 빈 상태를 보여주고, 캘린더에서 강조하지 않습니다.
