# 프론트 구현 핸드오프 문서

이 프로젝트의 프로토타입(`*.dc.html`)을 실제 앱 프론트엔드로 옮기기 위한 문서 묶음입니다.
프로토타입은 **디자인 소스**이고, 이 문서가 **구현 기준**입니다. 값이 어긋나면 프로토타입 파일의 값을 따릅니다.

## 프로토타입 파일 ↔ 화면 매핑

| 화면 | 프로토타입 | 경로(제안) |
| --- | --- | --- |
| 홈 | `홈.dc.html` | `/` |
| 하루 회고(챗) | `회고.dc.html` | `/reflect` |
| 일기 | `일기.dc.html` | `/diary/:date` |
| 쉼터 허브 / 행동카드 / 카드 상세 / 룸 | `쉼터.dc.html` | `/rest`, `/rest/cards`, `/rest/cards/:date`, `/rest/room/:slug` |
| 보관함(캘린더·리스트) | `보관함.dc.html` | `/archive?view=calendar\|list` |
| 리포트 | `리포트.dc.html` | `/report?week=` |
| 마이 | `마이.dc.html` | `/my` |
| 전체 화면(디바이스 랩) | `전체 화면.dc.html` | 프로토타입 전용, 구현 대상 아님 |

`data.js` = 시연용 랜덤 데이터 생성기. 실제 구현에서는 API로 대체하되, 목(mock) 서버 시드로 그대로 옮겨 쓸 수 있습니다(→ data-model.md).

## 구현 순서 제안

1. **토큰·전역 스타일** — 컬러/타이포/라운드/모션 토큰, 폰트 로드(Gaegu, Gowun Dodum)
2. **레이아웃 셸** — 375~430px 기준 세로 스택, 하단 탭바 5개, 상단 상태바
3. **공용 컴포넌트** — 탭바, 감정 칩, 감정 아이콘, 바텀시트, 슬라이드업 패널(키보드/시트), 토스트, 확인 모달
4. **홈** (일정 CRUD + 드래그 정렬 + 완료 시 감정 선택 시트)
5. **회고 → 일기** (챗 스텝 3개 → 일기 저장 → 행동카드 상세로 이동)
6. **보관함** (캘린더/리스트, 월 필터, 감정 필터, 검색)
7. **쉼터** (행동카드 캘린더·상세, 룸 3종)
8. **리포트** (주간 집계) → **마이** (설정·문의·탈퇴)

## 주의: 커스텀 한글 키보드

프로토타입은 웹에서 모바일 IME를 흉내내기 위해 **자체 한글 조합 키보드**를 구현해 두었습니다(홈/회고/보관함).
실제 네이티브·웹 앱에서는 **OS 키보드를 사용**하고, 이 키보드 UI는 구현하지 않습니다.
단, 키보드가 올라올 때의 레이아웃 규칙(하단 탭바 내려감, 화면 탭하면 닫힘)은 유지하세요 → app-flow.md의 "입력 레이어 규칙".
