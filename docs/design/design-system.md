## 3. 간격 · 형태

- 화면 좌우 패딩: **16~20px** (홈 카드 내부 20px)
- 카드 사이 간격: **8~12px**, 리스트 행 간격 8px
- 라운드: 필드 `10~14px` · 카드 `16~18px` · 큰 카드/시트 `20~22px` · 칩/버튼 `999px` · 상세 카드 `22px`
- 그림자: `0 1px 4px rgba(60,56,48,.05)` (얕은 카드) / `0 2px 8px rgba(60,56,48,.07)` / `0 8px 22px rgba(60,56,48,.16)` (떠 있는 카드·시트)
- 홈만 예외: 그림자 대신 `1.5px solid #4A3B2C` 테두리 + `0 3px 0 rgba(74,59,44,.12)`
- 곡선 언덕(섹션 전환): `border-radius:50% 50% 0 0 / 100% 100% 0 0`, 폭 140%(좌 -20%), 높이 54~64px를 26~34px 컨테이너로 잘라 씀
- 터치 타깃: 최소 44px (체크 원 22px는 부모 행 58px가 타깃)

## 4. 컴포넌트

### 4.1 하단 탭바
5개: 홈 / 쉼터 / 보관함 / 리포트 / 마이. 배경 `bg/nav`, 상단선 `line/nav`, 패딩 `9px 8px 14px`(홈은 `10px 8px 26px`).
아이콘은 30px(홈)/22px 라운드 사각형 테두리. 활성: 테두리 `#8C9A76` + 배경 `rgba(143,162,138,.14)` + 라벨 `#5F6B4D`, 비활성 `#C3C1B6` / `#95928A`.

### 4.2 일정 행 (홈)
높이 58px. `[완료 원 22px] [제목 16px] [드래그 핸들]`
- 미완료: 원 테두리 2px `#C7BCA9`, 배경 없음
- 완료: 원 배경 = 감정색(미선택 시 `#C4BCAF`), 제목 `#A79883`
- 원 탭 → 완료 토글(완료 시 감정 시트), 제목 탭 → 인라인 편집, 핸들 드래그 → 순서 변경

### 4.3 감정 선택 시트 (일정 완료 시)
바텀시트. 감정 9개 그리드 + "감정 없이 완료". **일정이 있어야만 진입 가능**하고, 선택은 건너뛸 수 있습니다.

### 4.4 감정 칩 (보관함 필터)
`padding:6px 13px`, `radius:16px`, 배경 = 감정색, 테두리 없음.
선택 시 `opacity:1 / scale(1.04)`, 비선택 `opacity:.42`. **같은 칩 재탭 = 필터 해제**("전체" 칩 없음).

### 4.5 행동카드
- 목록 카드: 상황 / 제안된 행동 / 수행 체크 + 느낀 점 입력. 카드 전체가 탭 타깃 → 상세로 이동(체크·입력은 `stopPropagation`).
- 상세: 화면 자체가 한 장의 카드(`radius:22px`, `bg #FDFBF5`). 상황 → 제안된 행동 → 수행/느낀 점 → **지난 기록 리스트**(날짜 · 수행 여부 · 느낀 점).

### 4.6 캘린더
7열 그리드. 요일 헤더 11px `#B9B2A2` (일요일 `#C98E7A`, 토요일 `#7E93A8`).
- 보관함: 셀 54px, gap 6px, 날짜 숫자 + 감정 아이콘 22px. 기록 있는 날 `rgba(255,255,255,.92)`, 없는 날 `rgba(247,244,237,.55)`, 선택일 `#3C3830`/흰 글씨.
- 쉼터(행동카드): 셀 27px, gap 5px. 카드 생성된 날 `#8FA28A` 채움, 선택일 `#3C3830`. 카드 없는 날은 `cursor:default`(선택 불가).

### 4.7 바텀시트 / 슬라이드업 패널
항상 마운트하고 `transform: translateY(100%→0%)` + `pointer-events` 토글로 여닫습니다(조건부 마운트 금지 — 닫힘 애니메이션이 사라짐).
배경 딤 `rgba(48,38,28,.32)`, 시트 `radius:22px 22px 0 0`, 패딩 `12px 20px 26px`.

### 4.8 토스트 (마이)
화면 하단 중앙, 어두운 알약 형태, 자동 소멸.

### 4.9 확인 모달
`left/right:30px`, 중앙 정렬, 취소(테두리)/실행(`#E4886C`) 2버튼. 탈퇴는 2단 확인.

## 5. 모션

| 상황 | 값 |
| --- | --- |
| 패널·시트 올라옴 | `transform .3s cubic-bezier(.3,.9,.3,1)` |
| 딤 페이드 | `opacity .24s ease` |
| 페이드 인 | `fadeIn .16~.28s ease` |
| 칩 상태 변화 | `opacity .18s ease, transform .18s ease` |
| 일정 드래그 | 이동 중 `scale(1.02)` + 그림자, 놓을 자리 점선 슬롯 |
| 호흡(감각 연못) | 4-7-8초 사이클, 원 `width/height 1s linear` |
| 챗 봇 발화 | 문장당 540ms 간격, 응답 대기 700ms |

`prefers-reduced-motion` 시 위 트랜지션을 0.01ms로 축소하고 슬라이드는 즉시 표시로 대체하세요.
