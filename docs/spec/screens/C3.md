## 규칙

- **하나만 고른다.** 여러 개를 허용하면 "지금 가장 가까운" 이라는 질문이 무너진다.
- 9종은 **한 화면에 3×3** 으로 다 보인다. 스크롤로 감추면 뒤쪽 감정은 선택되지 않는다.
- 선택은 배경 + **테두리 2px + 글자 굵기**를 함께 바꾼다. 점은 선택 여부와 무관하게 원색(`var(--eN)`)이다.
- 요약 카드가 **되돌릴 수 있음**을 말한다 — "지금 다시 골라도 괜찮아요".
- **임상 용어·강도 척도를 쓰지 않는다.** 감정에 숫자를 붙이지 않으므로 리포트도 높이로 말하지 않는다(`W1`).
