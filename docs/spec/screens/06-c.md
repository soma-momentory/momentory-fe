# 06-c · 관심 분야 · 기타 입력 중

**입력 중에는 글자 수만 센다.** 12자를 넘기면 더 입력되지 않고 오류 문구 없이 카운터 색만 바뀐다 — `04` 의 닉네임과 같은 규칙이다.

## 규칙

- 확정 기준은 **셋** — 키보드 `[완료]` · 입력 줄 밖 탭 · `[다음]`. 세 경우 모두 **앞뒤 공백을 다듬은 값**을 칩으로 바꾼다.
- **값이 공백뿐이면 확정하지 않고 기타 선택을 취소한다.** 빈 칩을 만들지 않는다.
- 값이 들어가면 **지우기 ×** 가 나타난다(시각 19px · 히트 44).
- **포커스 상태는 화면으로 그리지 않는다** — `.tfieldOn` 과 같은 규칙(강조 테두리 + 깜빡이는 캐럿)을 쓴다.
- 안내는 몇 개를 골랐는지 **사실만** 말한다. "3개까지예요" 같은 제한 경고를 미리 띄우지 않는다.
