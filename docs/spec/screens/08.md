## 규칙

- **"마지막으로,"를 쓰지 않는다.** 바로 다음 `09` 가 "마지막으로 하나만 더"라 충돌한다 — 마지막이라는 말은 캘린더 한 곳에만 둔다.
- 시간 선택은 **OS 피커**로 연다. 커스텀 휠을 만들지 않는다.
- `[알림 없이 쓸게요]` 는 채우지 않은 보조 버튼(`.quiet`)이다. 주 버튼과 같은 무게로 그리면 알림을 끄는 쪽이 기본값처럼 보인다.
