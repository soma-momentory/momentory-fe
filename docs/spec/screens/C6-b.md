# C6-b · 일기 · 바바가 함께 본 오늘 + 행동 카드

**둘째 면은 바바의 것이고, 회고를 마친 당시의 고정 스냅샷이 된다.** 저장 이후에는 다시 만들지 않는다 — 사용자가 자기 일기를 고쳐도 이 면은 그대로다([`A3-b.md`](A3-b.md)).

## 규칙

- **행동 카드는 한 장뿐이다.** 여러 장을 만들면 할 일 목록이 되고, 할 일 목록은 지키지 못한 것의 목록이 된다.
- 행동은 `C4-e` 에서 **사용자가 말한 것**을 옮긴 것이다. 바바가 새로 만들지 않는다.
- 관점은 **사용자의 문장을 부정하지 않는다** — "바바의 관점은 제안일 뿐이에요 · 내 문장이 우선이에요"를 화면에 둔다.
- 저장하면 `Diary` 한 장 + `ActionCard` 한 장이 남고 `C7` 로 간다. **한 문장 요약·점수·배지를 만들지 않는다.**
- 행동 카드는 **각 일기 아래**에 붙는다 — 따로 목록을 만들지 않는다(리포트 `W1` 의 「이어갈 한 가지」 한 장이 유일한 모아보기다).
