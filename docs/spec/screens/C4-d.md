# C4-d · 대화 · 방향을 고른 직후

## 규칙

- **칩에 쓰는 말은 사용자의 말이다** — 내부 분기명(`reframe`)은 저장만 하고 화면에 쓰지 않는다.
- `[변경]` 을 누르면 **같은 시트가 다시 열리고 그때까지의 대화는 지워지지 않는다.** 방향을 바꾸는 일이 대화를 버리는 일이 되면 아무도 바꾸지 않는다.
- 내부 흐름은 **감정 확인 → 관점 전환 → 균형 근거 → 사용자 문장 → 작은 행동**이다. 이 단계 이름을 화면에 쓰지 않는다.
- **사용자가 말하지 않은 성공을 만들지 않는다** — "해낸 부분도 있었나요?"는 질문이지 단정이 아니다.
- 기본 **3~5회 답변** 안에 마무리한다.
