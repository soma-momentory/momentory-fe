# C4 · 대화 · 첫 질문

**바바가 일정을 먼저 지목하지 않는다.** "면접 스터디는 어땠어요?"로 열면 오늘의 화제를 바바가 정하는 것이 된다. 무엇을 이야기하고 싶은지부터 묻고, 일정에 없던 일도 괜찮다고 먼저 말한다.

## 규칙

- **빠른 답변 칩·예시 placeholder 를 두지 않는다.** 보기를 주면 사용자는 자기 말 대신 보기 중 하나를 고른다.
- 감정은 **단정하지 않고 확인한다** — "우울하시군요"가 아니라 "우울한 마음이 가장 가까이 있군요".
- 한 메시지는 **2~3문장**, 질문은 한 번에 **하나**.
- 상단 알약은 `C3` 에서 고른 시작 감정이다. 대화 내내 자리를 지킨다 — 무엇을 안고 시작했는지 잊지 않게.
- `[잠시 쉬기]` 는 **자동 저장 후 홈에서 이어간다.** 저장 여부를 묻지 않는다.
- **진행률·단계 번호를 노출하지 않는다.**
