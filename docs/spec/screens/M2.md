# M2 · 회고 프로필 · 바꾼 것 없음

**바꾼 것이 없으면 `[저장하기]`가 잠긴다.** 누를 수 있는 저장 버튼은 "뭔가 바뀌었다"는 신호라, 아무것도 안 고친 화면에서 켜져 있으면 매번 눌러 확인하게 된다.

## 규칙

- **온보딩에서 묻지 않은 것을 여기서 편집하게 두지 않는다.** 반대로 물은 것은 전부 여기 또는 `M1` 의 다른 줄에 있어야 한다 — 쉬는 방법(`07`) 섹션이 그래서 있다.
- 선택 칩에 **체크 아이콘**을 붙인다 — 색·굵기만으로 표시하지 않는다.
- **`[변경하지 않고 나가기]`를 두지 않는다.** 나가는 길은 상단 뒤로가기 하나로 통일하고, 고치고 저장하지 않은 채 나가면 확인을 묻는다. 나가기 버튼이 둘이면 어느 쪽이 저장인지 매번 읽어야 한다.
- 관심 분야는 **최대 3개**(온보딩 `06` 과 같은 규칙).
- 쉬는 방법은 고른 것 + 대표 몇 개만 보이고 나머지는 `[＋ 더 고르기]` 로 편다 — 15개를 다 펴는 곳은 온보딩 `07` 이다.
