## 규칙

- **워드마크도 Pretendard 하나**를 쓴다. 명조는 쓰지 않는다 — 서체를 늘리는 대신 크기와 자간으로 위계를 만든다. 자간은 **.145em → .055em** 으로 좁혔다(2026-08-06) — 넓은 자간이 로고가 아니라 낱글자로 읽혔다.
- **워드마크와 슬로건 사이의 연결선을 두지 않는다.** 선이 둘을 갈라 놓아 한 덩어리로 읽히지 않았다. 여백 26px 로 대신한다.
- **먼지 3점을 걷어냈다.** 배경 장식이 바바보다 먼저 눈에 들어왔다.
- 그림자는 **92×8 / 24% 를 발밑에** 둔다 — 150×16 / 30% 는 캐릭터가 떠 있는 것처럼 보였다.
- 바바는 **알파 PNG** 만 쓴다(`전체모습/01_앉아서_인사_트림.PNG`). JPEG + `mix-blend-mode` 는 배경 사각형과 누런 번짐을 남긴다.
- **진행 바·퍼센트를 두지 않는다.** 최소 0.8초를 보장하고 준비되면 즉시 넘어간다. 1.5초를 넘기는 지연 상태(원본 `S0-b`)는 MVP 범위 밖이다.
- 모션은 `breathe`(scale 1→1.015 · 4.6s loop) · `glowPulse`(5.6s). **Reduce Motion 에서 전부 정지**한다.
