# 12-d · 순간 입력

**한 줄이면 충분하다고 화면이 말한다.** 제목·태그·감정 선택을 붙이면 순간이 일기가 되고, 일기가 되면 낮에 적히지 않는다.

## 상태

| 상태 | 화면 |
|---|---|
| `12-d` | 시트 — 취소 / 순간 남기기 / 저장 · 시각 · 본문 + 캐럿 · 각주 · 키보드 |

- 시각 "오후 3:12" · 본문 "회의가 생각보다 잘 끝났다"
- 각주 "정리하지 않아도 괜찮아요 · 한 줄이면 충분해요"

## 규칙

- **시각을 함께 보여준다.** 저장되는 순간이 곧 그 시각이지만, 밤에 되읽을 때 낮의 어느 지점이었는지가 순간의 절반이다(2026-08-05 에 뺐던 줄을 상류 개정판이 되살렸다).
- **감정을 함께 묻지 않는다.** 순간은 감정 기록이 아니다 — 감정은 `C3` 의 시작 감정과 일정별 감정에서만 정해진다.
- 저장은 상단 우측 한 곳뿐이고 `[취소]` 는 좌측이다. 하단에 큰 버튼을 두면 키보드와 겹친다.
- 순간은 **개수를 세지 않는다** — `dayCount` 는 일정만 센다.
- 입력 중 이탈·저장 실패(원본 `E*`)는 MVP 범위 밖이다.
