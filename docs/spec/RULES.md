## 불변 규칙

상류 `momentory.states.mvp.json` 의 `invariants` 와 `MVP.md` 4장을 옮긴 것이다. **각 문장이 테스트 하나**다.

**제품 전체**
- 홈은 **세 칸 고정** — 오늘 일정 / 순간 / 돌아보기. 회고 시각에는 진입만 자리를 옮긴다.
- 회고를 마치면 **일기 한 장이 남는다** — 점수·연속 일수·배지·축하 연출 없음.
- 리포트는 **일기 7편부터** 열린다.
- **되돌릴 수 있게 만든다** — 마침·감정은 토글, 확인 모달 없음, 삭제는 캘린더 원본을 지우지 않는다.
- **빈 상태 전용 레이아웃을 만들지 않는다** — 같은 템플릿의 흐린 한 줄로 수습한다.
- 예외 표시는 **상단 한 줄 + 해당 줄까지**, 입력은 막지 않는다. 실패로 말하지 않고 "올리는 중".
- **임상 용어·진단·평가 표현 금지.** 감정은 9종 이름으로만 부른다.
- 하루는 **새벽 4:00** 에 넘어간다.

**카피**
- **확정 범위가 아닌 약속을 화면에 쓰지 않는다**(암호화 · "나만 볼 수 있어요").
- **고르지 않은 항목을 부정형으로 강조하지 않는다**("연결 안 함" · 점선 원).
- 안내 문구는 **실제 데이터 처리와 같은 말**이어야 한다.
- **내부 용어(유형명·분기명)를 화면에 노출하지 않는다** — `feelings/reframe/solve/brief` 는 내부값이다.

**홈**
- 세 칸의 **순서는 어떤 상태에서도 바뀌지 않는다.**
- **채운 버튼은 화면에 하나뿐**이다(`.addr`).
- **일정 행의 터치는 둘** — 체크 원은 즉시 마침/취소, 제목·행은 상세 시트.
- **가져온 일정은 읽기 전용** — 제목 수정 없음, 삭제 대신 `hidden`. 수정·삭제는 `source=manual` 에만.
- 일정이 **5개를 넘으면** 5개까지 펼치고 `[n개 더 보기]` 로 접는다. 긴 제목은 **한 줄 말줄임**.
- 메모(순간)는 「오늘의 순간」 라벨 아래 모으고 **개수를 세지 않는다.**

**회고**
- **진행률·단계 번호 없음.**
- 한 메시지는 **2~3문장**, 질문은 한 번에 **하나**.
- 감정을 **단정하지 않고 확인**한다 — "~하게 느껴졌군요" · "~인 것 같아요".
- **사용자가 말하지 않은 성공·교훈을 만들지 않는다.** 행동은 사용자가 말한 내용에서 나온다.
- 기본 **3~5회 답변** 안에 마무리한다.
- **방향은 되짚기 다음에 묻는다** — 추천 없음, 아무것도 선택되지 않은 상태로 열리고 CTA 는 잠긴다. 확정은 CTA 를 눌러야 된다.
- **요약을 대화에 다시 쓰지 않는다** — 요약이 남는 자리는 일기 한 장이다.
- 감정 선택은 필수이고 **통과 버튼을 만들지 않는다.**
- **완료 화면은 허브가 아니다** — 홈으로 돌아온다.

**보관함**
- 일기는 **두 면**이다 — 내가 남긴 오늘(`A3`), 바바가 함께 본 오늘(`A3-b`). **두 면을 한 화면에 섞지 않는다.**
- **바바의 문장과 행동 카드는 회고를 마친 당시의 고정 스냅샷**이다 — 다시 만들지 않고, 사용자가 자기 일기를 고쳐도 바뀌지 않는다.
- `A4` 에서 고치는 감정은 **「이 일기의 감정 태그」**(목록·필터용)다. 원본 감정 기록은 그대로다.
- 달력 점은 **하루 최대 3개**, 색만으로 감정을 판단하게 하지 않는다.
- 필터 결과가 없어도 빈 상태 전용 레이아웃을 만들지 않는다.
- 연속 일수를 세지 않는다 — **장수(ordinal)만** 센다.

**리포트**
- 일기 **7편 미만이면 그래프를 만들지 않는다.** 잠긴 화면 대신 홈의 한 줄로 예고한다.
- 리포트는 평가가 아니라 **관찰**이다 — 점수·등급·실행률·최고 기록 금지.
- **감정은 점이다** — 강도를 입력받지 않으므로 크기·높이로 말하지 않는다.
- **문구를 기간에 매지 않는다** — 지난 주차를 넘겨볼 때도 같은 말이 맞아야 한다.

**마이**
- **온보딩에서 답한 항목은 빠짐없이 편집 경로가 있어야 한다.** 반대로 묻지 않은 것을 여기서 편집하게 두지 않는다.
- 연속 일수·점수·배지를 쓰지 않는다.
- **축하 알림을 만들지 않는다.**
- **하나의 설정을 두 줄로 나누지 않는다.**

## 접근성

- 탭 대상 **44pt 이상**. 선택지는 52pt(`.opt`), 주 버튼 54pt(`.pri`).
- 작은 글리프(지우기 × 19px, `.fchip` 34px, `.sbtnDel` 36px)는 시각 크기를 키우지 말고 **hitSlop 으로 44 를 확보**한다 — `.fchip::after` 가 그 방식이다.
- **화면 JSON 에서는 히트 영역을 `히트 44 · <이름>` 이라는 투명 rect 로 깐다**(`lib.mjs` 의 `hit44()`). 플러그인에 hitSlop 필드가 없어서 이름에 "(44pt 히트)" 라고 적어두면 문서일 뿐 노드가 아니다. `validate.mjs` 가 44 미만인 히트 노드와 이름만 44pt 인 노드를 잡는다.
- **깔지 않는 자리** — 줄 전체가 눌리는 `›` 표식, 탭바 칸, 44 트랙 안의 세그먼트 글자처럼 **이미 큰 부모가 탭을 받는 것**. 비활성 컨트롤(`W1` 의 `›`)도 넓히지 않는다. 읽기 전용 표시(`A3-b` 그날의 기록)도 대상이 아니다.
- 텍스트 **최소 11px**. 상류 `momentory.css` 의 `.wdn`(9.5px) · `.wdl`(10.5px)은 저장소에서 **11px 로 올렸다** — 리포트 `W1` 의 「화남/답답」 한 칸만 두 줄로 접힌다. 상류도 같은 하한을 쓰고 있다(`.f105{font-size:11px} /* 구 10.5 — 최소 11px */`).
- **선택 상태를 색만으로 표시하지 않는다** — 테두리 굵기(1→2px)와 글자 굵기를 함께 바꾸고, 필요하면 체크 아이콘을 더한다(`.chipOn` `.emOn`+`.emck` `.fchipOn` `.doptOn`+`.doptck`).
- 글자색은 semantic 6토큰만 쓴다 — `textStrong`(`P.ink`) `textBody`(`P.body`) `textCaption`(`P.slogan`) `textLegal`(`P.legalInk`) `textAccent`(`P.accentInk`) `textOnDark`(`P.textOnDark`). **Raw hex 금지.** 예외는 `dangerInk` 하나이고 아래 조건에서만이다.
- `primary #C2703D` 는 **장식 전용**이다(점·막대·테두리·토글 트랙). 글자가 얹히는 면은 `primaryDeep #A25B2C`.
- **`dangerInk #9B3B2F` 는 되돌릴 수 없는 동작(삭제)의 글자·테두리에만** 쓴다 — **면을 채우지 않는다.** 빨간 주 버튼은 누르기 쉬워지고, 되돌릴 수 있는 동작(마침 토글·감정 취소)과 위계가 뒤집힌다. 쓰는 곳은 `12-c` `[홈에서 숨기기]` · `A4` `[이 회고 삭제]` · `M1` `[회원 탈퇴]` 셋이다.
- **삭제를 색만으로 구분하지 않는다.** `dangerInk` 는 `legalInk` 와 명도가 비슷해 색맹 사용자에게는 같은 회갈색으로 보인다 — 구분은 라벨이 이미 하고 있어야 한다.
