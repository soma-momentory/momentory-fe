# 제품 계약 지도

이 문서는 **지도**다 — 규칙 본문을 복제하지 않고, 무엇이 어디 있는지와
구현이 스펙과 어긋난 지점만 관리한다. 규칙 자체는 [`docs/spec/`](spec/SNAPSHOT.md)
스냅샷이 정본이다.
