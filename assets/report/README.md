# 리포트의 땅 — 「이번 주 감정들」 카드의 모래 언덕

[`src/components/report/WeekGround.tsx`](../../src/components/report/WeekGround.tsx) 가
조약돌 일곱 더미 아래에 이 한 장을 깔고, 요일 글자는 그 아래에 선다.

| 파일         | 무엇                                                              |
| ------------ | ----------------------------------------------------------------- |
| `ground.png` | 모래 언덕 두 겹 — 뒤 언덕이 왼쪽에서, 앞 언덕이 오른쪽에서 솟는다 |

- 2168 × 275 · 투명 배경 · **가로세로비 7.88** — 화면은 `aspectRatio` 로 이 비율을 지키고
  높이가 카드 폭을 따라간다(늘리지 않는다)
- 받은 그림(흰 배경)에서 배경만 걷어낸 것이다 — 다시 만들 때:

  ```bash
  python3 scripts/keyout-report-ground.py ~/Downloads/<받은 그림>.png assets/report
  ```

- ⚠ **받은 그림의 흰 바탕이 순백이 아니다**(231~254 잡티). 스크립트가 문턱을 두어 그 잡티를
  배경으로 눕힌다 — 문턱 없이 자르면 상자가 원본 크기 그대로 남는다(스크립트 머리말)
- ⚠ **짙은 갈색 언덕 한 겹을 먼저 그렸다가 물렸다**(2026-09-12 · 「별로다」) — 그 띠가 조약돌보다
  먼저 눈에 들어왔다. 지금 두 겹은 배경과 같은 온도의 모래색이라 뒤로 물러난다
