# 감정 스티커 — 보관함 달력 칸의 얼굴 10종

`src/components/ds/EmotionSticker.tsx` 가 이 열 장을 감정 id 로 고른다.
파일 이름은 **서버 감정 키**(`features/retro/model/retro.ts` 의 `EMOTION_KEYS`)와 같다 —
`happy` `proud` `calm` `tired` `stuck` `lethargic` `anxious` `depressed` `angry` `frustrated`.

- 132×132 (44pt @3x) · 투명 배경 · 정사각. 여백을 잘라 낸 앱용이다.
- ⚠ **2026-09-10 에 열 장을 통째로 갈아 끼웠다.** 앞선 그림(2026-09-07 반입)은 사람 얼굴
  결이었고, 지금 것은 **카피바라 얼굴**이라 홈 카드·감각연못의 캐릭터와 한 식구가 된다.
  **이름도 규격도 그대로**여서 코드는 한 줄도 바뀌지 않았다.
- **원본은 받은 그림 열 장**. 받은 파일은 투명 미리보기를 그대로 찍은 것이라 **알파가
  전부 불투명**했고 배경 자리에 체커 무늬와 워터마크 획이 RGB 로 들어 있었다 —
  [`scripts/keyout-emotion-stickers.py`](../../scripts/keyout-emotion-stickers.py)
  가 그 배경을 걷어 내고 잘라 이 열 장을 만든다.
  ⚠ **가르는 방법이 무늬에서 색으로 바뀌었다.** 옛 그림에서는 「피곤함」의 머리가
  `(222,220,220)` 이라 체커의 회색과 같은 색이어서 무늬(국소 명도 폭)로 갈라야 했는데,
  새 그림에서는 그 방법이 **오히려 가장자리를 갉는다** — 체커 칸이 19~29px 로 커져서
  칸 한가운데가 7×7 창에 통째로 들어가고, 그 자리는 무늬가 없어 배경으로 안 잡힌다.
  얼굴에 닿은 칸이 얼굴에 붙어 **네모난 털처럼 삐져나왔다.** 새 그림은 가장 옅은
  얼굴(「피곤함」의 베이지)조차 채도가 11 이상이라(체커는 2 이하) **채도 문턱 하나로**
  깨끗이 갈린다 — 그 얼굴에서 「채도 ≤ 6 · 밝기 ≥ 150」인 화소는 0.000% 다.
- 더 좋은 원본(투명 PNG 진본)이 오면 **같은 이름·같은 규격으로 덮어쓰면 코드는 손대지
  않아도 된다.** 그때 위 스크립트는 필요 없다.
- **그림이 든 색은 코드가 다시 정하지 않는다**(`DESIGN.md` 「쉼터」의 카피바라와 같은
  판단) — 화면은 tint 하지 않고 받은 색 그대로 그린다.
