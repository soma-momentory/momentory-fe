# 현재 회고 자산 (2026-10-29)

`diary-star-background.png`는 사용자가 별 여백을 넓혀 다시 제공한 「갈색 격자와 골드 별무늬 배경.png」 원본(841×1870)을 그대로 복사한 채팅 배경이다. 일정 확인·대화 화면과 Lab 기기 프레임에 같은 이미지를 표시한다.
화면에서는 `cover`로 원본 비율을 유지한다. 기기 비율에 따라 가장자리는 일부 잘리지만 별과 격자를 늘리지 않는다.

`baba-diary.png`는 사용자가 제공한 `Baba.png` 원본(1200×1600, 투명 PNG)을 그대로 복사한 것이다.
`RetroBabaArtwork`가 투명 여백을 화면에서만 잘라 앉은 모습과 키보드 위 상반신을 표시한다.
고개 내민 상태의 감은 눈은 같은 그림 위의 SVG 오버레이이며, 동작 줄이기 설정을 따른다.
아래 빈백·고개 내민 별도 PNG는 이전 시안의 자산으로 현재 회고 화면에서는 사용하지 않는다.

# 회고 대화 화면의 그림

## `baba-beanbag.png` — 왼쪽 아래에 앉은 바바

[`src/features/retro/ui/RetroBaba.tsx`](../../src/features/retro/ui/RetroBaba.tsx) 가
`app/retro/talk.tsx` 의 `ChatScaffold` `companion` 으로 화면 왼쪽 아래에 고정해 세운다(260dp · 150 → 300 → 260 으로 맞췄다).

- 900 × 818(300dp @3x 까지 선명하다) · 투명 배경 · 그림 상자에 딱 맞게 잘랐다
- **원본은 사용자가 준 투명 PNG**(2026-09-11 · `…03_40_57-Photoroom.png` · 1225 × 1284). 처음 받은 흰 배경
  원본에서 **사용자가 Photoroom 으로 배경을 걷어 낸 것**이고, 같은 날 「이거 그대로」로 갈아 끼웠다.
  [`scripts/keyout-retro-baba.py`](../../scripts/keyout-retro-baba.py) 는 이 원본의 배경을 건드리지 않고,
  그림 바깥에 흩어진 **알파 8 미만 잔여**만 지운 뒤 자르고 줄인다(잔여를 두면 그림 상자가 캔버스 끝까지 커진다).
  - 그전에는 흰 배경 원본을 스크립트가 직접 걷어 냈다(가장자리에서 이어진 흰 칸 + 윤곽선 바깥 2px 섞임을
    알파로 되돌림). 알파 없는 원본을 주면 스크립트가 여전히 그 길로 간다.
- **색을 다시 칠하지 않는다** — 받은 색 그대로다.

원본이 다시 오면 스크립트로 **같은 이름에 덮어쓰면 된다.** 비율이 바뀌면
`RetroBaba` 의 `ASPECT` 를 함께 고친다.

## `baba-peek.png` — 입력창 위로 고개를 내민 바바

[`src/features/retro/ui/RetroBabaPeek.tsx`](../../src/features/retro/ui/RetroBabaPeek.tsx) 가
**키보드가 올라와 있는 동안만** 입력창 윗변 위, 앉은 바바와 코가 같은 가로 자리에 세운다(`ChatScaffold` 의 `companionRaised` · 120dp).
앉은 바바가 키보드에 덮여 안 보이는 동안의 자리다(2026-10-03 · 사용자 요청).

- 480 × 349 · 투명 배경 · 그림 상자에 딱 맞게 잘랐다
- **원본은 사용자가 준 흰 배경 그림**(판 너머로 고개를 내민 카피바라 · 1312 × 1199 webp). 아래를 가리던 흰 판도
  배경과 함께 걷었다 — 판 자리에 앱의 입력창이 온다. 판 위에 걸쳐 그려진 앞발은 남는다
- 몸이 판에 잘린 줄은 윤곽선 없이 곧게 자른다 — 그 줄이 입력창 윗변에 맞는다.
  그 아래로 내려온 앞발의 몫(그림 높이의 5.86%)을 스크립트가 출력하고, `RetroBabaPeek` 의 `PAW_RATIO` 가 든다
- **머리·몸만 원본보다 낮게 내렸다**(`BODY_DROP` 50px · 2026-10-03 · 「너무 튀어나와 있다」 → 100 은 「너무 줄었다 · 몸통이 살짝 보였으면」 사용자 요청).
  앞발은 떼어 내 제자리에 두고 머리·몸만 내린 뒤 판 윗변에서 다시 잘랐다 — 입 아래로 몸통이 살짝 보인다.
  앞발 뒤에 가려 있던 몸은 원본에 없지만, 내려간 자리가 제자리 앞발에 그대로 덮인다.
  가로 상자는 내리기 전 그림으로 잡아 **앞발의 크기·자리가 그대로다**
- **두 앞발을 조금 안쪽으로 모았다**(`PAW_GATHER` 한쪽당 15px · 2026-10-03 · 「손을 아주 조금만 서로 모이게」 → 25 에서 「아주 조금 다시 멀어지게」
  사용자 요청). 앞발이 비운 자리 뒤의 몸은 원본에 없어 둘레 몸 색으로 번져 메웠다(cv2 inpaint)
- **색을 앉은 바바에 맞춰 옮겼다**(사용자 요청) — 원본은 몸이 조금 더 붉고 갈색이 밝았다. 몸 · 볼 · 갈색 ·
  윤곽선 네 자리의 대표색을 두 그림에서 재서 짝지었다
  ([`scripts/keyout-retro-baba-peek.py`](../../scripts/keyout-retro-baba-peek.py) 의 `PALETTE`)

원본이 다시 오면 스크립트로 같은 이름에 덮어쓴다. 비율이 바뀌면 스크립트가 출력하는 `ASPECT`(폭 × 높이) · `PAW_RATIO` · `NOSE_X` 를 함께 고친다.

### `baba-peek-blink.png` — 눈만 감은 같은 그림 (깜빡임)

`RetroBabaPeek` 이 `baba-peek.png` 위에 겹쳐 두고 몇 초에 한 번 잠깐 켠다(2026-10-03 · 사용자 요청 ·
박자는 `ds` 의 `babaBlink`). **같은 스크립트가 같은 상자로 잘라** 눈 말고는 픽셀이 같다 — 둘 중 하나만
다시 만들면 겹쳤을 때 어긋난다. 원본 눈 자리를 둘레의 몸 색으로 덮고(가장자리를 흐려 자국이 안 남게)
아래로 둥근 짧은 선(‿)을 그었다. 눈 자리·선 모양은 스크립트의 `EYES` · `LID_*` 다.
