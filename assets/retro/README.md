# 현재 회고 자산 (2026-10-29)

`diary-star-background.png`는 사용자가 별 여백을 넓혀 다시 제공한 「갈색 격자와 골드 별무늬 배경.png」 원본(841×1870)을 그대로 복사한 채팅 배경이다. 일정 확인·대화 화면과 Lab 기기 프레임에 같은 이미지를 표시한다.
화면에서는 `cover`로 원본 비율을 유지한다. 기기 비율에 따라 가장자리는 일부 잘리지만 별과 격자를 늘리지 않는다.

`baba-diary.png`는 사용자가 제공한 `Baba.png` 원본(1200×1600, 투명 PNG)을 그대로 복사한 것이다.
`RetroBabaArtwork`가 투명 여백을 화면에서만 잘라 앉은 모습과 키보드 위 상반신을 표시한다.
고개 내민 상태의 감은 눈은 같은 그림 위의 SVG 오버레이이며, 동작 줄이기 설정을 따른다.
이전 시안의 빈백(`baba-beanbag.png`) · 고개 내민(`baba-peek*.png`) 그림과 그 스크립트는 쓰는 곳이 없어 2026-11-09 에 지웠다.
