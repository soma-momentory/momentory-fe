# 감정 조약돌 — 「이번 주 감정」의 하루 한 장 12종

[`src/components/ds/EmotionPebble.tsx`](../../src/components/ds/EmotionPebble.tsx) 가 이 그림을
감정 id 로 고른다. 쓰는 곳은 **홈의 주간 줄**(`WeekEmotionStrip`)과 **리포트의 7일
흐름**(`WeekMoodRow`) 둘뿐이다.

파일 이름은 **서버 감정 키**(`features/retro/model/retro.ts` 의 `EMOTION_KEYS`)와 같다 —
`joy` `calm` `proud` `affection` `sad` `anxious` `angry` `disappointed` `ashamed` `confused` `sorry` `exhausted`.

⚠ **2026-11-14 대표 감정 12종으로 바꾸면서 열두 장을 통째로 다시 받았다**(사용자 반입). 파일 이름은
새 서버 키다. 열 장은 체커가 구워진 미리보기(약 330px)였고, 부끄러움(`ashamed`) · 미안함(`sorry`) 두
장은 진짜 투명 WebP(1254px)였다 — 스크립트가 앞의 것은 배경을 걷어 내고 뒤의 것은 알파를 그대로 쓴다.
감정 색 토큰(`ds/color.ts` 의 `emotion`)은 이 열두 장의 평균색이라 **그림을 바꾸면 토큰도 다시 잰다.**
[`assets/emotion/`](../emotion/README.md) 의 얼굴 스티커와 **이름이 같고 자리가 다르다**:
저기는 보관함 달력의 얼굴, 여기는 주간 줄의 조약돌이다.

- 96×96 (26dp @3x 를 넘기고 여유를 둔 값) · 투명 배경 · 정사각. 조약돌은 정원이 아니라 **모양이 조금씩 달라서**, 일곱 개가 나란히 서도 도장 찍은 것처럼 보이지 않는다.
- **원본은 받은 그림 열두 장**(2026-11-14 · 사용자 반입 · 첫 열 장은 2026-09-11). 얼굴 스티커와 같은
  사정으로 **알파가 전부 불투명**했고 배경 자리에 체커 무늬가 RGB 로 들어 있었다 —
  [`scripts/keyout-week-emotion-pebbles.py`](../../scripts/keyout-week-emotion-pebbles.py)
  가 그 배경을 걷어 내고 잘라 이 열두 장을 만든다.
- ⚠ **가장자리를 깎지 않는다.** 조약돌은 수채라 테두리가 부드러운데 한 겹을 깎으면 그 결이
  각진다. 알파만 흐려서 번짐을 남긴다(얼굴 스티커는 테두리가 또렷해 깎는 편이 깔끔했다 —
  같은 파이프라인이지만 이 한 줄이 다르다).
- ⚠ **워터마크 부스러기를 뗀다.** 스톡 워터마크의 획이 조약돌에 닿아 있으면 같은 덩어리로
  묶여 테두리에 점처럼 남는다. 마스크를 한 번 열고(erode→dilate) 다시 가장 큰 덩어리만
  취하면 가느다랗게 붙은 것이 떨어져 나간다.
- **그림이 든 색은 코드가 다시 정하지 않는다** — tint 하지 않고 받은 색 그대로 그린다.
  감정 원색 토큰(`emotion[id]`)은 **이 그림의 평균색을 잰 값**이라 점 · 도넛과 조약돌이 한 색이다
  (2026-11-14 통일 · 그 전에는 서로 달랐다). 주간 줄은 토큰이 아니라 그림을 그린다.

더 좋은 원본이 오면 **같은 이름·같은 규격으로 덮어쓰면 코드는 손대지 않아도 된다.**

## `no-emotion.png` — 감정 없이 끝난 일기의 빈 조약돌

일기는 썼는데 **감정이 추출되지 않은 날**의 칸이다(2026-09-11 · 사용자 반입). 테두리만 있는
조약돌이고, 열 장과 같은 96×96 이되 **여백은 5%** 다 — 칸이 원으로 잘려서 2% 면 오른쪽 아래 선이 끊긴다. **일기가 없는 날**은 여전히 `WeekEmptyDot` 이다.

- 원본은 **진짜 투명 PNG** 라 체커를 걷어 낼 일이 없다 —
  [`scripts/make-no-emotion-marks.py`](../../scripts/make-no-emotion-marks.py) 가 자르고 줄인다.
- ⚠ **선을 굵혔다**(원본 해상도에서 알파 팽창 13px). 원본 선은 캔버스 폭의 1% 라 26dp 에서
  0.25dp 가 되어 보이지 않는다.
- 리포트는 서버 칸이 「안 쓴 날」과 「썼는데 감정 없음」을 똑같이 `emotion: null` 로 주므로
  **로컬 일기 목록**으로 가른다(`app/(tabs)/report.tsx` 의 `writtenDates`).
