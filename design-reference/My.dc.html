규칙
  • 섹션 3개(앱 설정·지원·계정) — 모든 행은 Core List Cell
  • 프로필은 이니셜 아바타 + 기록 일수 (캐릭터 없음)
  • 「총 회고 12회」 → 「일기 12일 기록」 — 내부 용어 제거
  • 알림 설정 시트는 시간 변경 하나만 — 온보딩의 세로 휠 피커 재사용
  • 기본 정보 수정: 현재 값 목록 → 항목 선택 → 그 항목만 수정 → 저장
  • 수정 상세에는 건너뛰기·다음·설명 문구 없음 — 기존 값이 채워진 상태로 시작
  • 저장은 full-width 하단 고정 — 값이 그대로면 비활성, 하나라도 바뀌면 활성 → 저장 후 M3 복귀
  • 닉네임·나이는 키보드가 올라오면 저장 버튼이 키보드 바로 위에 붙고, 키보드가 내려가면 하단 CTA 위치(좌우 20 · Safe Area 34 위)로 돌아와요
  • 활성 저장은 M2 「완료」와 같은 초록(#7C9E86) · 라벨 #FFFDF8, 비활성은 #DDE7E0 · #A3B5A9
  • 온보딩 입력 컴포넌트(pill 입력·칩)는 재사용, 온보딩 플로우는 재사용하지 않음
  • 회원 탈퇴만 목록 밖 Text Button으로 낮춤
  • 새 설정 UI 패턴을 만들지 않았어요
