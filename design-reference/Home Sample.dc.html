3단계 — 홈 (기준 화면 · LOCK)

새 디자인 시스템만으로 홈을 조립했어요. 새로 만든 요소는 없고, 전부 Core·Momentory 컴포넌트 + 토큰이에요. 일정 체크·감정 시트·삭제 모달까지 눌러 볼 수 있어요. 다크 테마는 같은 마크업에 semantic 토큰만 갈아 끼운 결과예요 — 두 화면의 상태는 함께 움직여요.

기존 홈에서 바뀐 점
  • 하늘·초원 배경과 씬 일러스트 제거 → Background / Normal 단색
  • 1.5px 진한 테두리 카드 → hairline + Radius Large(16)
  • 일정 행 전체 재설계 → Core List Cell 하나로 통일
  • 29px 날짜 → Title 3, 22px Bold → Heading 2
  • ＋추가 칩 → Section Header trailing Text Button(＋추가)
  • 감정 요약은 Fill/Alternative 면에 담아 CTA보다 한 단계 낮은 위계
3단계 점검 결과
  • Spacing·Radius·타이포·아이콘 모두 시스템 값 — 임의값 없음
