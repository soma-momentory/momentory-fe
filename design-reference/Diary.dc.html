① 일정 떠올리기
  • 오늘 무슨 일이 있었는지 떠올리기만 함 — 감정·글쓰기 없음
  • 일정은 읽기 전용 — 완료만 16px 체크, 미완료는 아이콘 자리도 없음
  • 완료는 취소선 + Label Neutral, 미완료는 Label Strong
  • 메시지(왼쪽) + 정보 카드 — 온보딩 09와 같은 문법
  • CTA는 「다음」 하나 — 입력값이 없어 항상 활성
  • 일정이 많으면 카드 안 목록만 스크롤 · 하단 fade로만 힌트
  • ✕로 나가면 홈으로 복귀
② 마음 고르기
  • 9종을 같은 위계로 — 긍정·부정 구분이나 섹션 없음
  • 감정별 색 없음 — 미선택은 중립, 선택만 브랜드 초록 배경 + 2px 링
  • 3열 그리드 · 최소 높이 48 · 간격 10 · Radius 12
  • 단일 선택 — 다른 감정을 누르면 즉시 교체, 확인 모달 없음
  • CTA는 「이야기 시작하기」 — 선택 전 비활성
  • 강도·이유·점수 입력 없음 · 보조 설명 없음
③ 대화
  • ③-a는 ②의 질문·답변을 흐린 한 턴으로 남겨 대화가 이어져 보이게 해요
  • 질문 왼쪽 / 답변 오른쪽 · 지난 턴은 질문 0.55 · 답변 0.70 (확정값)
  • 턴 사이 28 · 질문↔답변 14 (온보딩과 동일)
  • 텍스트 질문 = 하단 입력창 고정 · 선택형 = 입력창 숨기고 칩 + 「보내기」
  • 전송은 종이비행기 버튼만 — 키보드는 줄바꿈, 빈 값이면 전송 불가
  • 입력창은 1줄에서 시작해 3줄까지 위로 자동 확장 · 최대 높이 뒤에는 내부 스크롤 · 전송 버튼은 오른쪽 하단 고정
  • 자동 스크롤: 새 질문이 나타나면 그 질문이 입력창 바로 위에 충분히 보이는 위치까지 자동 이동
  • 과거 대화는 지우지 않고 위로 쌓임 — 위로 스크롤해 다시 볼 수 있고, 보이는 지난 턴만 투명도를 낮춤
  • 「직접 쓸게요」를 고르면 칩·보내기가 사라지고 질문 아래 바로 입력창 (③-d2, 별도 상태 표시 없음)
  • 질문 유형 3종: 자유 입력(③-a·b·c) · 선택형(③-d) · 척도(③-e) — 원본 C1·C3·C2와 1:1
  • 척도는 슬라이더가 주인공 — 숫자는 결과값이라 Headline 1 Medium으로 낮춤
  • 화자 이름·아바타·꼬리 없음 — 위계는 정렬과 타이포로만
  • 마지막(③-g)은 「일기로 정리하기」 — 입력창 없이 CTA만
④ 결과
  • 정리 중은 Spinner + 두 줄 안내 — 진행률·시간 표시 없음
  • 여기서 대화 문법을 끝내고 읽기 레이아웃으로 전환 (말풍선 없음)
  • 일기에는 제목이 없어요 — 헤더는 「8월 13일의 일기」(Title 3) + 날씨
  • 대화 원문은 결과 화면에 다시 보여주지 않아요 — 대화는 과정, 일기는 결과
  • 본문 아래 「오늘 일정」을 함께 기록 (원본 구조)
  • CTA는 「일기 저장하기」 + 보조 「직접 고치기」 → ④-c에서 본문 수정
  • 고치기는 뒤로가기로 나가고 「저장하기」로 확정 — 새 화면 문법을 만들지 않고 입력 컴포넌트만 재사용
  • 저장 후 행동카드 생성 여부로 분기 — ④-d1(없음) / ④-d2(있음)
  • 카드가 없는 날은 아무 설명도 하지 않아요 (「오늘은 카드가 없어요」 금지)
  • ④-d2의 카드는 쉼터 R2와 같은 anatomy·같은 문구 — 수행 체크는 쉼터에서만
판단이 필요한 부분
  • 진행 표시를 넣지 않았어요 — 온보딩과 같은 규칙
  • 대화 도중 ✕로 나갈 때 임시 저장 여부는 예외 상태에서 정할게요
  • 일정이 0개인 경우는 예외 상태라 아직 안 만들었어요
