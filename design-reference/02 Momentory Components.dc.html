Momentory Components

Momentory 도메인에만 있는 컴포넌트예요. Core를 최대한 재사용하고, 여기서만 새 요소를 정의해요.

4-1 · Social Login Button

각 플랫폼 공식 디자인 정책을 우선해요 — Momentory 토큰으로 바꾸지 않아요. 높이 48 · Radius Medium(12) · Fill 너비.

4-2 · Emotion Item

9개 감정 선택 전용 요소예요. 칩·카드 느낌 없이 55% 틴트 원 + 라벨만. Selected는 원색 2px 링과 진한 라벨로 구분해요 — 눌러 보세요.

감정 이름은 기획 확정값으로 교체해요. Pressed는 scale 0.96 + 스크림, Selected 여부는 회고 UX 확정 뒤 결정 — 여기서는 단일 선택으로 구현했어요.

4-3 · Schedule List Item

Core List Cell 재사용: Leading=Checkbox, Trailing=드래그 핸들 + 더보기. 새 디자인 언어를 만들지 않아요.

완료 상태는 Label/Assistive + 취소선. Optional source는 Description 슬롯을 그대로 써요.

4-4 ~ 4-6 · Question Message · User Response · Chat Input

오늘 하루 중에 가장 기억에 남는 순간은 언제였어요?

점심에 잠깐 걸었던 산책이요. 바람이 좋았어요.

좋네요. 그 순간의 기분을 한 단어로 표현하면요?

Question Message — 말풍선·아바타·화자 라벨 없이 Body 1 Reading 좌측 정렬. 위계는 타이포와 정렬로만 만들어요.

User Response — Fill/Normal 배경의 낮은 위계 블록, 과한 bubble 장식 없음.

Chat Input — Empty(전송 비활성) · Typing · Filled · Sending · Disabled. 입력해 보면 전송 버튼이 살아나요.

4-7 · Measure Input

점수형 회고 질문 = 질문(Body 1) + Core Slider 조합이에요. 새 컨트롤을 만들지 않아요.

오늘 하루, 스스로에게 몇 점을 주고 싶어요?

{{ measureValue }}/ 10
아쉬웠어요충분했어요

4-8 · Diary List Item

보관함 하루 단위 목록 — Core List Cell에 감정 도트(Leading)와 메타(Description)만 얹어요.

4-9 · Empty / Fallback

일정 없음 · 기록 없음 · 검색 결과 없음 · 오류 공통 구조: Icon + Heading + Description + Optional CTA. 일러스트는 쓰지 않아요.
