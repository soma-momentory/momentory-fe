4단계 — 일정 (정상 상태)

홈에서 일정을 조작할 때 실제로 보게 되는 상태만 만들었어요. 별도 페이지를 만들지 않고 홈 위에서 입력 바·메뉴·모달로 처리해요. 일정 완료는 체크박스 한 번으로 끝나고, 감정은 회고에서만 받아요. 저장 실패 같은 예외는 넣지 않았어요.

규칙
  • 추가·수정 모두 하단 입력 바 하나를 재사용 — 별도 페이지 없음
  • 추가는 ＋ 버튼 또는 키보드 「완료」 — 입력이 없으면 둘 다 비활성
  • 수정은 Primary 링 + 「일정 수정」 캡션으로만 구분, 취소/저장 병행
  • ⋮ 메뉴는 Core Menu — 수정하기 / 삭제하기(negative) 2행
  • 메뉴는 바깥을 누르면 닫혀요 (⋮ 다시 누르면 열림)
  • 삭제는 되돌리기 없이 확인 모달 1회
  • 순서 변경은 꾹 누른 행만 떠오르고(그림자+Primary 링) 나머지는 흐려짐
  • 이동 중에는 놓일 자리에 빈 슬롯 표시 · 드롭하면 바로 기본 상태로 복귀(완료 버튼 없음)
  • 완료는 체크박스 한 번 — 감정 입력 없음, 취소선 + Label Neutral
판단이 필요한 부분
  • 감정은 일정 완료가 아니라 회고에서만 받아요 (5단계)
  • 순서 변경 진입을 꾹 누름으로 잡았어요 — ⋮ 메뉴 항목으로 옮길 수도 있어요
  • 삭제 되돌리기(Undo Toast)로 바꾸면 모달을 없앨 수 있어요
