세 화면의 역할
  • R1 = 진입 — 행동카드가 있다는 사실만, 카드 전체가 진입점(「보기 →」)
  • R2 위계: 오늘 카드만 흰 카드(Primary) · 지난 행동카드는 배경 위 직접 배치(Secondary)
  • R2 = 날짜별 카드 + 수행 상태 3단계(a 수행 전 → b 느낀 점 입력 → c 저장) · 캘린더는 날짜 탐색만
  • R3 = 같은 행동카드의 누적 기록 — 행동 자체가 제목
  • R1에서는 캘린더·수행 기록을 설명하지 않아요
규칙
  • 왼쪽은 상태(「아직 하지 않았어요」/「수행했어요」), 오른쪽은 행동 버튼(「했어요」/「수행 취소」) — 체크박스 없음
  • 「했어요」를 누르면 카드 안에서 바로 느낀 점 입력창이 열려요 (전송은 종이비행기)
  • 느낀 점은 선택 — 「남기지 않아도 괜찮아요」, 저장 후에는 읽기 상태 + 「고치기」
  • 입력창은 1줄(52px)에서 최대 3줄까지만 · 읽기 블록도 3줄에서 … 처리, 전체는 「자세히 보기」에서
  • R2 캘린더는 3가지를 분리해요 — 카드 존재는 텍스트 대비, 수행은 날짜 아래 작은 초록 dot, 선택은 초록 아웃라인 (배경 채움·범례 없음)
  • 선택 날짜는 Primary 링 · 기본 상태에서 스크롤 없이 캘린더 전체가 보여요
  • R3 목록은 느낀 점이 있을 때만 두 번째 줄을 노출해 밀도를 낮춤
  • 쉼터에는 아직 행동카드만 — 기능이 늘면 R1에 항목을 더해요
