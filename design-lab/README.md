# Momentory Design Lab

기존 앱의 38개 라우트 화면을 확인하는 독립 로컬 디자인 랩이다. 운영 Expo 앱 코드는 변경하지 않는다.

## 실행

Node.js 22.12 이상에서:

```bash
cd design-lab
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 연다. 빌드 검증은 `npm run build`로 한다.

## 페이지

왼쪽의 **기존 앱 · 전체 화면**에서는 38개 화면을 한 페이지에 펼쳐 본다. 카드를 누르거나 **현재 앱 · 화면 미리보기** 페이지를 선택하면 화면 하나를 스마트폰 크기로 크게 볼 수 있다. 화면 선택과 페이지 위치는 URL 해시에 저장되므로 새로고침과 브라우저 뒤로가기로 유지된다.

iPhone 13 mini(375×812pt), iPhone 16e(390×844pt), iPhone 16 Plus(430×932pt) 논리 화면 크기를 선택할 수 있다. 전체 화면 목록은 가독성을 위해 65%로 축소 표시하고, 개별 미리보기는 100%로 표시한다.

38개 화면 모두 현행 앱을 iPhone 13 mini 시뮬레이터에서 직접 캡처했다. 이 중 일정 수정, 회고 대화, 일기 확인·편집, 일기 상세, 주간 리포트 5개는 예시 데이터를 넣어 캡처했으며 배지로 구분한다. 화면 미리보기는 정지 이미지로서 실제 로그인·API·OS 키보드 동작은 제공하지 않는다. 과거 홈 캡처는 현행 앱과 달라 사용하지 않는다.

캡처는 `public/app-captures/`에 저장되어 있다. 기존 앱 코드는 변경하지 않았으며 시뮬레이터의 실행 중인 상태에만 예시 데이터를 넣었다. 빌드 산출물 `dist/`는 커밋하지 않는다.
